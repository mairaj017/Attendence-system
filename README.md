# Attendance System

A React + TypeScript + Vite dashboard for Uswa College Islamabad attendance tracking.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Structure

- `src/components/DashboardCards.tsx` — attendance KPI cards
- `src/App.tsx` — application shell
- `src/main.tsx` — React entry point
- `src/index.css` — Tailwind and global styles
